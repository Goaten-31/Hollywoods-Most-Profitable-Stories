# Hollywood Profits: a data analytics dashboard using python; cleaning, exploring and visualizing the data
This project serves as a simple analysis of the given dataset containing information regarding revenue as well as audience
and critic scores for movies released from 2007-2011\
This project uses UV as its project manager for easier and faster package management and code sharing\
It utilizes many of the data oriented Python libraries to explore this dataset.\
[Here reside the datasets in Google Sheets](https://docs.google.com/spreadsheets/d/1Mz2uoPx3gNWdMourSHdaU8xCaDZNrXgrTYLNeMC-p8Q/edit?usp=sharing)
